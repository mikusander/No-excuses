Dev Server Non Raggiungibile

L'app No Excuses Dev non è riuscita a collegarsi al server Vite in esecuzione sul PC.

Verifiche Rapide
  1. Il comando npm run dev deve essere attivo su questo PC.
  2. iPhone e PC devono essere connessi alla stessa rete Wi-Fi.
  3. Se l'indirizzo IP del PC cambia, digitalo sopra e tocca Riconnetti.
  4. Su Safari puoi anche navigare a: http://192.168.1.146:5173
